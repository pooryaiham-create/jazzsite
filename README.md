# EchoWave

A simple and modern static website for a music-focused YouTube channel.

## What is included
- Responsive landing page
- Featured tracks section
- Playlists section
- Simple admin placeholder page
- Mobile-friendly design

## Run locally
From the project folder, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/
```

## Publish on GitHub
1. Create a GitHub repository.
2. Upload this folder to the repository.
3. Open the repository settings.
4. Enable GitHub Pages from the root folder.

## Notes
This is the first release and intentionally simple. It is ready for GitHub publishing and can be expanded later with uploads, a database, or a custom backend.
